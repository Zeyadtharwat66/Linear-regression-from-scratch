# Linear Regression from Scratch

A simple implementation of **Linear Regression using Gradient Descent** in Python without using machine-learning libraries such as scikit-learn.

The project demonstrates how model parameters can be optimized manually using gradient descent.

## 🚀 Technologies

* Python
* NumPy
* Matplotlib
* Gradient Descent

## 📁 Project Structure

```text
Linear-regression-from-scratch/
├── code.py
└── README.md
```

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Zeyadtharwat66/Linear-regression-from-scratch.git
```

Navigate to the project:

```bash
cd Linear-regression-from-scratch
```

Install the required libraries:

```bash
pip install numpy matplotlib
```

## ▶️ Running the Project

Run the Python script:

```bash
python code.py
```

## 📌 Main Concepts

* Linear regression
* Gradient descent
* Parameter optimization
* Sum of Squared Errors (SSE)
* Data visualization

## 🛠️ How It Works

The model learns a line of the form:

```text
y = θ₀ + θ₁x
```

Gradient descent iteratively updates the parameters to reduce prediction error.
